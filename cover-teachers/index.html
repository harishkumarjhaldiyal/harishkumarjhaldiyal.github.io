Automatic Substitute-Cover Matching

When a teacher calls in sick, this reads the school's master timetable, works out exactly which periods need covering, and suggests a substitute for each one — subject-matched first, then balanced so the same few people don't get picked every time. Currently being piloted with my school's assistant principals. Everything below — every teacher, timetable, and email — is entirely fictional.

🎯

Subject-match first

Free teachers are ranked by whether they already teach that subject, then by how many recent covers they've done, then alphabetically. Subject match always wins — fairness only breaks ties.

⚠️

Busy-teacher warning

Flagged if a teacher is already teaching 3+ full periods that day, or 2+ periods plus a Flex duty. Informational only — it never changes who gets auto-picked, just warns before you confirm.

✉️

One consolidated draft

Every arrangement for the day — however many teachers are out — gets grouped into a single styled email, not one message per period.

Every slot also shows the 2nd and 3rd-ranked alternatives as one-click "Next best" chips — useful when you don't want one person covering three periods in a row. Try marking a teacher absent below.
