Automated integrity monitoring

A live-monitoring tool I built for the whole high school. For every student, it runs three mechanical checks against their linked Google Docs, using only Drive/Docs API data, and keeps re-checking on a five-minute cycle so nothing goes stale.

Copy-paste / word-count jump

Fetches each Drive revision's real historical text and computes an exact word-count delta between consecutive revisions — flagged as a date range to review, not an accusation.

External collaborator

Lists each document's Drive permissions and flags any account outside the school's own domain.

Late-night editing pattern

Converts each revision's timestamp to local time and flags anything landing in the 11pm–6am window.

i Ticking a Reviewed box doesn't silence a flag forever — it just means only new evidence after that date re-triggers it. Try it below.
